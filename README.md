# RoIron Website

Official website for RoIron — Roblox Optimizer.

## Setup

```bash
npm install
npm start
```

## Deploy

Works with Vercel, Netlify, or any Node.js host.

```
vercel
```

## Structure

```
public/        → Static assets (CSS)
views/         → EJS templates
server.js      → Express server
vercel.json    → Vercel config
```
